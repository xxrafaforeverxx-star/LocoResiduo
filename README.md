# LocoResiduo

Aplicación auxiliar para estimar la distancia de residuo a partir de la longitud total del tren y la velocidad seleccionada, con apoyo de GPS.

## Desarrollo
- npm install
- npx expo start

## APK de prueba
El perfil preview de EAS genera un APK Android instalable. La compilación requiere una cuenta Expo y un token configurado como secreto EXPO_TOKEN en GitHub Actions.

**Aviso:** herramienta auxiliar experimental. No sustituye sistemas embarcados, señalización, normativa ni procedimientos operativos ferroviarios. Debe validarse exhaustivamente antes de cualquier uso en servicio.
